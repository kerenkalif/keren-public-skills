# Keren Kalif – Skills for Claude

Skills for Claude by Keren Kalif, a computer science lecturer. Each skill lives in its own folder with a `SKILL.md`.

## Skills

| Skill | What it does |
|---|---|
| [kerenkalif-moodle-quiz-from-slides](kerenkalif-moodle-quiz-from-slides) | Turns lecture slides into a question bank, a validated Moodle XML file (one category per presentation) and an optional quiz with random questions. Works for any subject; Hebrew/RTL and English/LTR. |
| [keren-dev-manager-general](keren-dev-manager-general) | Hebrew guidelines for a "development manager" session in Claude Code, for any project: breaking a feature into work units, running implementer/reviewer/researcher subagents, worktrees, review by risk, deployment checks, and a `STATUS.md` handoff file. |

## Install

- **Claude (web / desktop):** download [kerenkalif-moodle-quiz-from-slides.skill](https://github.com/kerenkalif/keren-public-skills/raw/main/kerenkalif-moodle-quiz-from-slides.skill) and upload it in Customize → Skills. The same applies to [keren-dev-manager-general.skill](https://github.com/kerenkalif/keren-public-skills/raw/main/keren-dev-manager-general.skill).
- **Claude Code:** copy the skill folder into `~/.claude/skills/`.
